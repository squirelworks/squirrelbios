# SquirrelBIOS v2.1.1 — v2.1.0 with all six firmware images

The same firmware as v2.1.0, from the same commit (`f572f71`), released again
so that every image is attached. The v2.1.0 release on GitHub was published
with only the three legacy images; this one also has the three UEFI-class
images and a `SHA256SUMS.txt` that covers all six. Nothing in the code
changed, so the firmware banner still reads `SquirrelBIOS 2.1.0`.

What the firmware does is described in the
[v2.1.0 notes](https://github.com/squirelworks/squirrelbios/releases/tag/v2.1.0):
x86-64 UEFI-class firmware with ACPI 6.x, SMBIOS 3.x, a CSM, SMP, Secure Boot
and NUMA tables, plus UEFI-class firmware for AArch64 and RISC-V `virt`.

## Release assets

Built from `f572f71` by the Draft release workflow, after `make test` passed
on that commit.

| File | What |
|------|------|
| `SquirrelBIOS-2.1.1-x86_64-uefi.fd` | 1 MB x86-64 UEFI-class firmware with CSM (`qemu-system-x86_64 -bios`, `q35` or `pc`) |
| `SquirrelBIOS-2.1.1-aarch64-uefi.fd` | AArch64 `virt` UEFI-class firmware (`qemu-system-aarch64 -M virt -bios`) |
| `SquirrelBIOS-2.1.1-riscv64-uefi.bin` | RISC-V `virt` SBI plus UEFI-class firmware (`qemu-system-riscv64 -M virt -bios`) |
| `SquirrelBIOS-2.1.1-x86-pc.rom` | 64 KB x86 PC BIOS (`qemu-system-i386 -bios`) |
| `SquirrelBIOS-2.1.1-aarch64-virt.bin` | AArch64 `virt` Linux `Image` hand-off firmware |
| `SquirrelBIOS-2.1.1-riscv64-virt.bin` | RISC-V `virt` M-mode SBI firmware |
| `SHA256SUMS.txt` | SHA-256 of the six files |
