# SquirrelBIOS v2.3.0

Measured boot becomes a product hand-off surface: with a TPM 2.0 (QEMU
`tpm-tis` + swtpm) the firmware publishes the TCG2 crypto-agile event log
through a Squirrel configuration table (`SQTL`) that agrees with the ACPI
TPM2 log area and `EFI_TCG2_PROTOCOL.GetEventLog`, and remains usable after
`ExitBootServices`. This is Phase G mark **M5** (`G-measured-handoff`) on
the path to product v3.0.0.

Still original code only (no EDK2, OVMF, SeaBIOS, OpenSBI, U-Boot,
OpenBIOS or SLOF). Owner tags and publishes; agents prepare this note and
a draft release with the six images + `SHA256SUMS.txt`.

## Measured event-log hand-off (M5)

- Configuration table `SQUIRREL_TPM_LOG_HANDOFF_GUID` / magic `'SQTL'`:
  physical log base, capacity, last-event address, TCG2 format, PRESENT /
  TRUNCATED flags, and the final-events table pointer.
- Same buffer as the TPM2 ACPI table log area and GetEventLog.
- Smoke: `x86_64-tpm-log-handoff` (`APP tpm-log cfg=ok acpi=ok log=ok
  tcg2=ok`, then after ExitBootServices `APP tpm-log ebs=ok`).
- Contract: `common/handoff.md`, design note
  `release-notes/measured-handoff.md`.
- `SQ_VERSION` is **2.3.0** (ESRT `FwVersion` encodes this string).
