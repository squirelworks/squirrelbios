# SquirrelBIOS v1.1.2

Roadmap Phase A is done: the tree is modular, every platform builds from
a named configuration, and the v1.0.0 follow-ups (#84) are closed. Real
Ubuntu Linux now starts on the x86 BIOS. The roadmap gave A1–A3 the
versions v1.1.0–v1.1.2; they ship together under this tag.

Tag target: `3c071e5` (the merge of #89). Includes #85–#89 on top of
v1.0.0. Still original code, still covered by `make test`.

## Build system (A1, #88)

- `make PLATFORM=<x86-pc|aarch64-virt|riscv64-virt> CONFIG=<name>`
  builds into `build/<platform>/<config>/`. `tools/mkconfig.sh` turns
  `configs/<platform>/<config>.cfg` into `config.inc` / `config.h`.
- `config-default` checks that each platform's `default.cfg` builds
  byte for byte what plain `make` builds.
- `configs/riscv64-virt/small.cfg` (`config-riscv-small`).

## x86 modules (A2, #89)

- `x86/squirrel-bios.asm` now holds constants, options and the layout,
  and includes one file per module under `core/`, `boot/`, `drivers/`
  and `tables/`. The default ROM is the same as before the split.
- `configs/x86-pc/minimal.cfg` leaves out ACPI, SMBIOS, the bzImage
  loader and the option ROM scan; `config-x86-minimal` boots it and
  `config-x86-minimal-noacpi` checks the ACPI tables are really gone.

## v1.0.0 follow-ups (A3, #86 and #87)

- The bzImage loader takes kernels of any size (64-sector chunks) and
  fills boot_params: E820 table, `alt_mem_k`, `type_of_loader`, command
  line `console=ttyS0,115200`. Kernels larger than RAM are refused.
- ATA units are probed once at POST with `IDENTIFY DEVICE`; the BDA
  hard-disk count (`0x475`) follows. `INT 13h` `AH=08h` returns `07h`
  for a unit that did not answer.
- ACPI: the FADT now points at a DSDT (header only, `0xFE0D0`).
- Optional `make linux-x86` boots Ubuntu's 6.8.0-31 kernel to the point
  of mounting a root file system.

## Known gaps

- No floppy, PCI enumeration, EDD or CD boot yet: those are Phase B
  (v1.2.x), already merging on main after this tag.
- ACPI has no PM blocks or FACS; text mode only; no UEFI.
