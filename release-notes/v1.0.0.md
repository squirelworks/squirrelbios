# SquirrelBIOS v1.0.0

A comprehensive **x86 PC BIOS** on QEMU: POST-shaped init, the IVT
services a boot sector and OS keep calling, ACPI and SMBIOS tables,
bzImage and option-ROM paths — still original code, still covered by
`make test`. No SeaBIOS, no EDK2, no UEFI.

Built on v0.3.0 (hand-off era) plus sections 8–11 of [TODO.md](../TODO.md).

## IVT surface (x86)

| Vector | Role |
|--------|------|
| `INT 08h` | IRQ0: PIT tick; advances BDA `0x046C` |
| `INT 09h` | IRQ1: keyboard; enqueues set-1 make codes |
| `INT 10h` | `AH=02/03` cursor, `06/07` scroll, `0E` teletype, `0F` get mode |
| `INT 13h` | `AH=00` reset; `02/03` CHS read/write; `08` params; `42/43` LBA read/write. `DL=0x80` master, `0x81` slave |
| `INT 15h` | `E820` memory map; `AX=2400`–`2403` A20 gate |
| `INT 16h` | `AH=00` read keystroke; `AH=01` check |
| `INT 1Ah` | `AH=00` tick count; `AH=02` RTC time (BCD) |

Every other vector is an `iret` that leaves flags alone. `IF` stays clear
at hand-off; IRQ0 and IRQ1 are unmasked on the PIC.

## Boot paths (x86)

- Primary master, or primary slave when the master is absent (`DL=0x81`)
- One-sector `0xAA55` hand-off; `SQBL` extra sectors; `S2OK` kernel at
  `0x8000`
- Linux `bzImage` (`HdrS`): PM kernel at 1 MB, flat protected-mode entry
- Option ROMs in `0xD0000`–`0xEFFFF` (`55 AA` + checksum → far call init)

## System tables

- ACPI 1.0 RSDP/RSDT/FADT in the ROM at `0xFE000` / `0xFE020` / `0xFE050`
- SMBIOS 2.4 `_SM_` entry point at `0xFD000` (Type 0 / 1 / 127)

## Known gaps

- No VESA / SVGA BIOS; text mode only
- No UEFI
- FADT has no FACS/DSDT; PM register blocks are zero
- No floppy; only the primary IDE channel
- AArch64 and RISC-V remain platform firmware (hand-off / SBI); their
  extra polish is on the secondary track and does not block this tag

## `make test`

58 cases at this tag (x86 through option ROMs and bzImage, plus the
AArch64 and RISC-V suites from v0.3.0).
