# SquirrelBIOS v1.2.2

The first block of roadmap Phase B. The x86 BIOS now boots from
floppies and CDs, sets up PCI devices, and reaches disks past 128 GB.
The Squirrel-OS/2 1.0.0 floppy image boots on it, and so does a real
ISOLINUX CD, as far as its `boot:` prompt. The roadmap numbered B1–B3
as v1.2.0–v1.2.2. They ship together under this tag.

Tag target: `7b0fb54` (the merge of #94). Includes #90–#94 on top of
v1.1.2. This is still original code, and `make test` still covers all
of it.

## Floppy (B1, #90)

- 82077 FDC driver for 1.44 MB diskettes. Transfers use ISA DMA
  channel 2, and IRQ 6 stays masked. Drives come from CMOS `0x10`, and
  the BDA equipment bits match them.
- `INT 13h` `DL=00h/01h` supports these calls:
  - `AH=00h`: reset.
  - `AH=02h` and `03h`: read and write. They continue across heads and
    cylinders, and return `09h` when the buffer crosses a 64 KB
    boundary.
  - `AH=08h` and `15h`.
- `INT 1Eh` points at the diskette parameter table.
- A: boots before the hard disk, with `DL=00h`. A diskette without
  `0xAA55` is reported, and the hard disk boots instead.

## PCI (B2, #91)

- POST walks bus 0 through configuration mechanism #1 and places every
  BAR: memory from `0xE0000000`, I/O from `0xC000`, and 64-bit BARs
  below 4 GB. It then turns decoding on.
- On i440fx, the PIIX3 routes PIRQA–D to IRQ 10, 10, 11 and 11, and
  each device's Interrupt Line matches. On q35, Interrupt Line is
  `0xFF`.
- PCI BIOS 2.10 (`INT 1Ah` `AX=B1xx`) supports these calls:
  - `B101`: installation check, which returns `'PCI '`.
  - `B102` and `B103`: find a device by ID or by class.
  - `B108`–`B10D`: config reads and writes.
- A `$PIR` interrupt routing table sits in the F000 segment.

## Large disks and CD boot (B3, #92 and #94)

- LBA48: a transfer that reaches sector 2^28 uses `READ/WRITE SECTORS
  EXT`. Disks up to 2 TB are supported.
- EDD 3.0 supports these `INT 13h` calls:
  - `AH=41h`: the fixed disk access subset.
  - `AH=44h` and `47h`.
  - `AH=48h`, with the ISA/ATA device path.
- El Torito no-emulation boot from ATAPI on either IDE channel. It runs
  when no hard disk boots, enters the image with `DL=E0h`, and serves
  these calls on the CD in 2048-byte blocks:
  - `INT 13h` `AH=00h`, `41h`, `42h` and `48h`.
  - `AX=4B00h` and `4B01h`.

## Known gaps

- PCI covers bus 0 only. Bridges, q35 interrupt routing and a BIOS32
  entry are still to come.
- CD boot supports no-emulation images only.
- ISOLINUX also calls `INT 10h` `AH=01h/09h` and `INT 16h` `AH=10h/11h`,
  which are not implemented yet.
- No AHCI, NVMe or USB yet. Those are B4–B8 (v1.3.x and v1.4.x).
