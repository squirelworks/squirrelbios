# SquirrelBIOS v1.3.1

Roadmap B4 and B5. The x86 BIOS now boots from SATA disks on an AHCI
controller and from NVMe drives, and serves both through `INT 13h`.
Squirrel-OS/2 1.0.0 boots to its shell from a q35 SATA disk and from
`-device nvme`. The roadmap numbered B4 and B5 as v1.3.0 and v1.3.1.
They ship together under this tag.

Tag target: `e4007a1` (the merge of #99). Includes #95 and #97–#99 on
top of v1.2.2. This is still original code, and `make test` still covers
all of it.

## SATA (B4, #97)

- When no IDE hard disk answers, POST finds an AHCI controller (class
  `01:06:01`) on PCI bus 0, resets it, and takes the first port with a
  SATA disk. It prints `disk: SATA disk on AHCI port N`.
- That disk is `DL = 80h`. It boots like an IDE disk (boot sector,
  SQBL, S2OK, bzImage), and every `INT 13h` disk call serves it.
- Transfers use `READ DMA EXT` and `WRITE DMA EXT`, and each write is
  followed by `FLUSH CACHE EXT`. A failed command restarts the port.
- `AH=48h` names the disk as `PCI` / `SATA` with the port number.

## NVMe (B5, #99)

- When no IDE or SATA disk answers, POST finds an NVMe controller (class
  `01:08:02`), sets up its admin queues, and identifies namespace 1. It
  then creates one I/O queue pair and prints `disk: NVMe disk
  (namespace 1)`.
- Namespace 1 is `DL = 80h`, served the same way. Reads and writes use
  NVMe Read and Write, with Flush after each write. Transfers use PRP
  lists where they need them.
- `AH=48h` names it as `PCI` / `NVMe` with namespace ID 1.

## Memory layout (#95, #98)

- The extended BIOS data area is now 20 KB at `0x9B000`–`0x9FFFF`. It
  holds the AHCI command structures and the four NVMe queues, and the
  memory map reserves it.
- BDA `0x040E` points at it, and BDA `0x0413` is now **620 KB**
  (640 KB in v1.2.2). SQBL loads and `INT 13h` buffers must end
  below `0x9B000`.

## Known gaps

- One boot disk of these kinds: SATA only when no IDE disk answered,
  NVMe only when neither did. No port multipliers. NVMe serves
  namespace 1 with 512-byte blocks only, and its BAR must be below 4 GB.
- `INT 13h` on SATA and NVMe works from real mode only, not from
  virtual 8086 mode. Buffers must be word-aligned (SATA) or
  dword-aligned (NVMe).
- No USB yet. That is B6–B10 (v1.4.x).
